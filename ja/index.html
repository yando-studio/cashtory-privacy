Y&O STUDIO（以下「開発者」）は、CashToryの利用者のプライバシーを尊重します。本ポリシーは、アプリ内の情報、第三者のSDKが取り扱う情報、利用者が開発者に直接送る情報を区別し、それぞれの利用目的・保存場所・管理方法を説明します。日本の利用者に適用される範囲で、個人情報の保護に関する法律その他の関係法令に従います。

概要：CashToryに会員登録・ログイン・開発者が運営するデータサーバーはありません。家計簿の記録やレシートから保存した取引情報は利用者の端末に保存され、開発者は閲覧できません。一方、広告およびGoogle ML KitのSDKは下記の技術情報をGoogleに送信することがあります。利用者がメールを送信した場合に限り、お問い合わせ内容と一部のアプリ・端末情報を開発者が受け取ります。

1. 取り扱う情報と保存場所

1.1 利用者の端末内に保存される情報

利用者が入力・保存した収入、支出、振替、資産、負債、カード、分割払い、カテゴリ、定期取引、お気に入り、日ごとのメモ、記念日、車両情報・走行・整備記録、言語・通貨・通知表示などの設定は、端末内のSQLiteデータベースで取り扱います。レシートから読み取った店舗名、日付、金額、取引のうち、利用者が確認して保存した内容も含まれます。利用者が選んだ車両写真は縮小してデータベースに保存され、JSONバックアップに含まれる場合があります。レシート画像とは異なり、保存した車両写真はアプリ内に残ります。これらを保存する開発者のサーバーはなく、開発者は遠隔で閲覧できません。

1.2 GoogleのSDKが取り扱う可能性のある技術情報

  • Google Mobile Ads SDK：IPアドレスとそこから推定されるおおよその位置、アプリ・広告とのやり取り、パフォーマンス・診断情報、Android広告ID、アプリセットID。
  • Google ML Kit：端末・アプリ情報、端末またはインストールの識別子、パフォーマンス指標、API設定、入出力サイズ、機能・モデルのバージョン、モデルのダウンロードや機能の実行・リソース解放に関するイベント、エラーコード。

レシート画像と認識した文字そのものは端末上で処理され、開発者のサーバーやGoogleのサーバーには送信されません。SDKが取り扱う技術情報の詳細は第6項を参照してください。

1.3 お問い合わせで開発者が受け取る情報

アプリの「お問い合わせ」を選ぶと端末のメールアプリが開き、アプリのバージョン、OS名・バージョン、端末のモデル名、アプリの言語・通貨設定が本文に自動入力されることがあります。利用者は送信前に内容を確認・削除できます。メールを実際に送信した場合に限り、送信元アドレス、本文および残した端末情報を開発者が受け取り、お問い合わせへの回答、問題の調査、サービス改善に使用します。

1.4 通常は取得しない情報

会員登録・ログイン機能はありません。通常の利用で、開発者が氏名、電話番号、連絡先、通話履歴、正確なGPS位置、本人確認番号などを別途取得することはありません。ただし、利用者がメールに自ら記載した内容は受け取ります。

JSON・CSVを読み込むシステムのファイル選択画面で選んだファイルを読み込みます。一時的なコピーがアプリ内に残る場合があります。端末全体のストレージ権限は要求しません。

3. レシートの撮影・文字認識

対応端末ではGoogle ML Kit Document Scannerを標準の撮影方法として使用します。Google Play開発者サービスが撮影画面や関連モデルを提供し、レシートの輪郭検出や傾き補正を行います。必要なリソースはダウンロードされることがあります。

スキャナーが使用できない場合はアプリ内カメラに切り替わります。端末に保存済みの画像を選ぶ場合はAndroidのフォトピッカーを使用します。Google ML Kit Text Recognitionは端末上で文字を認識します。対応する文字体系には日本語、韓国語、ラテン文字、デーヴァナーガリー文字が含まれ、必要なモデルがダウンロードされることがあります。

  • 画像と認識した文字の全文は、開発者またはGoogleのサーバーには送信されません。
  • 画像と認識した文字の全文はアプリのデータベースには保存されません。利用者が保存した店舗名・日付・金額・取引のみ残ります。
  • スキャナーの結果ファイルは端末内の一時領域に残る場合があります。写真ライブラリから選択した元画像はCashToryによって削除されません。

ML Kitは第1.2項の技術情報を診断や利用状況の測定のためGoogleに送信することがあります。これらの通信にはHTTPSが使用されます。

4. 広告

Android版ではGoogle AdMobとGoogle Mobile Ads SDKを使用して広告を表示します。広告の配信、測定、不正防止のため、SDKは第1.2項の広告関連情報を取得・共有することがあります。

同意やプライバシーに関する選択肢が必要な地域では、Google User Messaging Platform（UMP）が選択画面を表示する場合があります。画面が提供される地域では、アプリ内の広告プライバシー設定から利用可能な選択肢を再確認できます。Androidの広告設定やGoogleのマイアドセンターでも広告関連の設定を管理できます。

パーソナライズド広告を利用しないことを選んでも家計簿の基本機能は使用できますが、広告の表示や安全性に必要な限定的な技術情報の処理は続く場合があります。

5. 保存・バックアップ

家計簿データは端末内のアプリ専用SQLiteデータベースに保存され、開発者のクラウドには保存されません。保存した車両写真は自動・手動のJSONバックアップに含まれる場合があります。アプリが端末の専用領域に自動バックアップを作る場合、設定された件数を超えると古いバックアップから削除されます。

利用者が手動バックアップやエクスポートを実行した場合、JSONまたはCSVファイルを利用者の選んだ保存先に作成します。メール、メッセージアプリ、クラウドストレージへ送ったファイルには、各サービスの規約やプライバシーポリシーが適用されます。アプリをアンインストールしても、外部に保存したファイルは自動では削除されません。

CashToryはallowBackup=falseを設定し、Androidの自動クラウドバックアップは使用しません。ただしAndroid 12以降の一部端末では、メーカーによる端末間の直接転送まで防げない場合があります。アプリの削除や機種変更前には、必要に応じてJSONを手動保存してください。

7. 保存期間と削除

情報保存期間・削除方法
家計簿データ・設定・保存したレシートの取引情報・車両情報と写真利用者が削除、アプリデータを消去、またはアプリをアンインストールするまで端末に保存。
レシート画像・認識文字の全文データベースには保存されません。一時ファイルはOSによる管理またはアプリデータの消去まで残る場合があります。
端末内の自動バックアップ保存件数の上限に従う置換、アプリデータ消去、またはアンインストールまで保存。
外部にエクスポートしたJSON・CSV選択した保存先から利用者が削除するまで残ります。
お問い合わせメールと含まれるアプリ・端末情報お問い合わせ対応と必要なフォローアップが終わるまで保管し、その後開発者のメールアカウントから削除します。
Google SDKの技術情報情報の種類、目的、利用者の設定、およびGoogleのポリシーに従います。

開発者は端末内の家計簿データを代わりに削除できません。エクスポート先のサービスでの削除方法は、そのサービスを確認してください。

8. 子どものプライバシー

CashToryのGoogle Play上の対象年齢設定は18歳以上です。子ども向けのアプリではなく、会員登録や年齢確認の機能はありません。開発者はアプリを通じて子どもの氏名や連絡先を意図的に取得しません。子どもがメール等で情報を送信したことを把握した場合は、適用法令に従って確認し、必要な保護措置を講じます。保護者は第12項にお問い合わせください。

9. 利用者による管理

  • 端末内の記録はCashToryで閲覧・修正・削除し、JSONバックアップやCSVとして出力できます。
  • カメラ権限はAndroidの設定で変更できます。レシート認識を使わずに手入力もできます。
  • 広告IDやGoogleの広告設定はAndroidまたはGoogleの設定で管理できます。利用可能な地域ではアプリ内の広告プライバシー設定から選択を変更できます。

開発者が保有するお問い合わせ情報についての請求は第12項をご利用ください。Googleが独自に取り扱う情報に関する手続きはGoogleのプライバシーポリシーをご参照ください。

10. 安全管理

家計簿データは端末内に保存されます。GoogleのSDKが送信する技術情報はTLSまたはHTTPSで通信中に暗号化されます。開発者が受け取ったお問い合わせメールについては、アカウントへのアクセス制限、認証、お問い合わせ対応と必要なフォローアップが終わったメールの削除など、取り扱う情報の性質に応じて安全管理に努めます。

利用者も端末の画面ロックやOSの更新を利用し、外部に保存したJSON・CSVを安全に管理してください。どの保存方法も絶対的な安全性を保証するものではありません。

13. 日本の利用者への追加事項

13.1 利用目的と取扱い

開発者が直接保有する情報は、利用者が送信したお問い合わせメールとそこに含まれる情報です。第1.3項に記載の目的で使用します。端末内の家計簿情報は開発者が取得・保有しません。GoogleのSDKによる技術情報の取扱いとその目的は第1.2項、第4項、第6項に記載しています。

13.2 国外での取扱いと第三者サービス

開発者は韓国に所在します。日本から送信されたお問い合わせメールは、日本国外で処理され、メールサービスのサーバーにも保存されることがあります。GoogleのSDKが技術情報を日本国外のサーバーで取り扱うこともあります。Googleは全てのデータ項目に共通する単一の処理国・保存期間を示していません。第三者提供・国外移転に関する日本法上の取扱いは、Googleとの契約、実際のSDK動作、対象となる情報に応じて判断されます。本ポリシーだけで法令上必要な同意を取得したことにはなりません。

13.3 保有個人データに関する請求

日本の法令が適用される場合、開発者が保有するご自身の情報について、利用目的の通知、開示、訂正・追加・削除、利用停止・消去、第三者提供の停止、第三者提供記録の開示を請求できます。第12項のメールに、対象となるお問い合わせと希望する手続きをお知らせください。請求に応じるため、必要最小限の本人確認または代理権の確認をお願いする場合があります。適用法令上の例外がある場合を除き、法令に従い対応します。

端末内の家計簿記録は開発者が保有していないため、開発者が代わりに開示・修正・削除できません。アプリの機能やAndroidの設定から利用者自身で管理できます。

13.4 苦情・安全管理

個人情報に関する苦情は第12項で受け付けます。開発者が保有するお問い合わせ情報について、アクセスの制限や不要な情報の削除など、必要かつ適切な安全管理措置を講じます。漏えい等が疑われる場合には事実関係を確認し、対象となる事案について適用法令に従い必要な報告・通知を行います。

14. ブラジルの利用者への追加事項

ブラジルのLGPDが適用される場合、利用者は処理の確認、開示、訂正、不要または違法な情報の匿名化・停止・削除、データの移行、共有先や同意を拒否する選択肢についての情報、同意の撤回、法令上認められる異議申立てを第12項のメールで求めることができます。ポルトガル語の請求も受け付けます。お問い合わせメールは対応と必要なフォローアップが終わった後に削除します。

開発者は韓国に所在し、メールやGoogle SDKの技術情報がブラジル国外で取り扱われる場合があります。現在のAdMob設定にはブラジル向けLGPD専用の同意画面はありません。詳細はブラジル・ポルトガル語版をご確認ください。
